12 列（3 尺寸 × 4 等級）不得重複或缺漏、tier 費率推導、燃料／水艙容量、維護間隔、陣營

**工具不修改 `data/**`**（P7 只讀，數值調整屬資料卡）。

| 參數 | 值 | 說明 |

## 8. 敏感項（校準時唯一需要盯的數字）

### 8.1 大型 Mk.IV：30 日餘裕 +2.93%

- 平均係數 0.9778（T4、I=12、L=1.0）、平均輸出 1466.71、門檻 1425.0。
- 這是全表唯一低於 +15% 餘裕的檔位；需求 §5.5 明確列為校準敏感項。
- 會直接讓它 FAIL 的改動：**磨損率加快或維護停機變長**，使平均係數掉到 0.95 以下。
- 依需求 §20.2 的 config 允許範圍（維護間隔 4–20 日）重算：I=4 → 係數 0.9645、平均 1446.8、
  餘裕 +1.53%；I=6 → 0.9711、平均 1456.7、餘裕 +2.22%；I=12 → +2.93%。**縮短間隔不會直接 FAIL
  （config 下限 4 日仍過）**，但會迅速吃掉餘裕；需求 §5.5「任何縮短維護間隔的改動都會讓它 FAIL」
  是比公式更嚴格的口頭敘述，列為文件敘述與公式的差異（見 §9）。
- 真正會破線的情境：維護間隔 < 約 2 日（低於 config clamp）、或磨損／停機被加大到係數 < 0.95。
  任何調整都只需重跑 `dotnet run …` 一次即可重新判定。
